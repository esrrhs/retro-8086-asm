# 8086 汇编语言项目合集

本项目合集整理自 CSDN 上传的原创 16 位 8086 实模式 DOS 汇编项目，包含小游戏、图形动效、高精度算法、字符处理以及模块化子程序等不同应用场景的完整汇编源码（`.asm`）。

## 各项目功能与技术实现详解

### 1. 01_贪吃蛇汇编版 (`01_贪吃蛇汇编版`)
* **作用与功能**：
  基于 DOS 16 位实模式下的图形化经典“贪吃蛇”游戏。玩家使用键盘上下左右方向键控制蛇身移动，吃到食物后蛇身增长，碰撞边界或自身则判断结束。
* **主要文件**：
  * `exx.asm``EXX.EXE`：增强版完整游戏程序（推荐运行），内含食物机制、分数与速度延时控制。
  * `snake.asm``snake.EXE`：基础版游戏框架，包含蛇身链式移动结构与坐标计算。
  * `readme.txt`：作者提示，说明直接运行 `EXX.EXE` 即可开始；若速度过快可通过调节 `time` 变量控制延时。
* **核心技术点**：
  * **结构体定义**：使用 `struc` 定义 `point` 结构体（`x`, `y`, `color`），通过数组维护蛇身节点列表 `snakepoint point 100 dup(< >)`。
  * **BIOS 图形与键盘中断**：
    * `INT 10h` 进行图形像素绘制与颜色填充。
    * `INT 16h`（扫描码判断）捕获方向键：`UP (48h)`、`DOWN (50h)`、`LEFT (4Bh)`、`RIGHT (4Dh)`、`QUIT (01h)`。
  * **碰撞检测与移动**：蛇头移动时将前一身体节点坐标依次传递；检测蛇头坐标是否与边界或食物坐标重合。

### 2. 02_汇编小创意 (`02_汇编小创意`)
* **作用与功能**：
  CGA 图形模式下的弹性粒子碰撞动画。屏幕中的运动像素点带有初始速度向量，碰撞到屏幕边缘时自动反弹，并根据动态坐标计算颜色渐变效果。
* **主要文件**：
  * `小创意.asm`：完整的图形动画源码。
  * `小创意.EXE`：编译后的可执行文件。
* **核心技术点**：
  * **图形模式初始化**：调用 `INT 10h` (`AH=00h, AL=04h`) 切换至 320×200 四色 CGA 图形模式。
  * **物理运动与反弹**：
    * 维护运动点结构体 `screenpoint`（`x`, `y`, `v_x`, `v_y`, `color`）。
    * 每次刷新位置：`x = x + v_x`，`y = y + v_y`。
    * 边界判断：当坐标越界时对速度取反（`neg`）实现物理碰撞反弹。
  * **动态颜色计算**：`color = x + y` 产生彩色的轨迹效果；使用 `INT 10h AH=0Ch` 写像素点。

---

### 3. 03_任意两数相乘 (`03_任意两数相乘`)
* **作用与功能**：
  高精度大数乘法计算器。可接收用户从控制台输入的两个任意长度多位十进制正整数字符串，计算并输出乘法结果。
* **主要文件**：
  * `任意两数相乘.asm`：高精度大数乘法源码。
  * `任意两数相乘.EXE`：编译后的可执行程序。
* **核心技术点**：
  * **带缓冲区的键盘输入**：使用 DOS `INT 21h AH=0Ah` 从控制台接收带格式缓冲区的大数字符串。
  * **模拟手工列竖式乘法**：
    * 从被乘数和乘数的末位（个位）逆序扫描字符，转为数值后逐位相乘。
    * 维护中间运算数组与最终结果数组，精确处理每一步运算的进位（Carry）。
  * **格式化输出**：将计算结果转回 ASCII 字符并输出到控制台。

---

### 4. 04_任意长字符串排序 (`04_任意长字符串排序`)
* **作用与功能**：
  字符排序程序。接收用户输入的字符串，并按照 ASCII 码升序进行就地（in-place）排序后输出。
* **主要文件**：
  * `任意长字符串排序.asm`：字符串排序源码。
  * `任意长字符串排序.EXE`：编译后的可执行文件。
* **核心技术点**：
  * **输入处理**：调用 `INT 21h AH=0Ah` 读取字符串，根据缓冲区第二个字节获取实际输入的字符个数 `NUM`。
  * **冒泡排序算法**：
    * 寄存器 `bx` 指向当前比较的两个相邻字符。
    * 使用 `cmp ah, [bx]` 比较，若前大后小则执行字节互换（swap）。
    * 引入有序标志位 `lj`，当一整轮遍历无交换时提前跳出循环。
  * **控制台回显**：排序完成后通过 `INT 21h AH=09h` 直接打印以 `$` 结尾的排序后字符串。

### 5. 05_汇编画方框 (`05_汇编画方框`)
* **作用与功能**：
  演示 8086 汇编下的**模块化编程与堆栈传参**规范。主程序通过堆栈传递坐标参数，跨模块调用远程过程（FAR Procedure）完成图形界面的清屏与实心方框绘制。
* **主要文件**：
  * `ex1.asm`：调用方主程序。
  * `ex6.asm`：被调用的公共图形子程序模块。
* **核心技术点**：
  * **堆栈传参规范**：
    * 主程序依次将左上角及右下角坐标 `push x1`, `push y1`, `push x2`, `push y2` 压栈，然后 `call draw`。
    * 子程序通过建立基址指针栈帧：`push bp; mov bp, sp`，从 `[bp+12]`、`[bp+10]` 等偏移中解析参数。
    * 子程序返回时使用 `ret 8` 自动平衡 4 个字（8 字节）的堆栈参数。
  * **双重循环点阵填充**：
    * 外层循环遍历 `x` 坐标，内层循环遍历 `y` 坐标。
    * 调用 `INT 10h AH=0Ch` 逐点画线填充整个矩形区域。
  * **模式恢复**：绘制后等待用户按任意键（`INT 16h AH=00h`），退出前通过 `INT 10h AL=03h` 恢复 DOS 标准 80×25 文本模式。

---

### 6. 06_二次方科学运算 (`06_二次方科学运算`)
* **作用与功能**：
  基于二进制浮点形式（以 2 为底的指数与尾数）的科学运算库，支持基础的加、减、乘、除运算及对阶操作。
* **主要文件**：
  * `oper.asm`：核心运算过程模块（导出 `public operation`、`public answer, answer_`）。
  * `ex.asm`：测试驱动程序（导入 `extrn operation:far` 并输出运算结果）。
* **核心技术点**：
  * **尾数与指数表示**：运算数以 `(尾数, 阶码)` 形式传入，例如 `ah` 存储尾数，`al` 存储 2 的幂次阶码。
  * **加减法对阶处理**：比较两数阶码差值，利用算术右移 `sar` 将较小数的尾数按差值对阶，并处理进位与下溢。
  * **乘除法运算**：
    * 乘法：尾数相乘，阶码相加。
    * 除法：尾数相除，阶码相减。
  * **跨模块符号链接**：使用 `PUBLIC` 与 `EXTRN` 伪指令实现多模块间的符号导出与导入。

## 编译与运行环境说明

上述项目均为 16 位 DOS 程序，在现代 64 位操作系统（Windows 10/11、Linux、macOS）下需使用 **DOSBox** 模拟器运行：

### 1. 运行已有可执行文件
打开 DOSBox 后执行：
```bat
mount c /path/to/assembly_code
c:
cd 01_贪吃蛇汇编版
EXX.EXE
```

### 2. 重新编译汇编代码（使用 MASM 5.06.0 或 TASM）
单模块程序（如 `04_任意长字符串排序`）：
```bat
masm 任意长字符串排序.asm;
link 任意长字符串排序.obj;
任意长字符串排序.exe
```

多模块链接程序（如 `05_汇编画方框`）：
```bat
masm ex1.asm;
masm ex6.asm;
link ex1.obj + ex6.obj;
ex1.exe
```
